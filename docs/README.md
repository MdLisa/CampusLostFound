# 校园寻物站文档导航

本目录按开发计划、接口约定、测试与交接记录分类。平时从本页进入，不必顺序阅读全部阶段文档。

截至 2026 年 10 月 28 日，A、B 的代码已整合到 master，用户已反馈最新安装包测试完成；当前工作是正式前端。接口仍为 0.2，局域网通信 protocolVersion 仍为 2。本次整理只调整文档位置和说明，不修改代码或接口。

## 现在优先看什么

1. [前端开发计划](plans/前端开发计划.md)：前端当前要做的页面、开发顺序、方法对应和验收。
2. [共同接口约定](api/共同接口约定.md)：字段、状态和 16 个 HTTP 接口的唯一维护位置。
3. [A B 联调交接清单](testing/后端B与A联调清单.md)：实际代码整合、回调约定和测试交接，先读顶部最新整合记录。
4. 涉及选图和图片读取时查 [第五步说明](testing/第五步测试与交接说明.md)，涉及页面返回、断网和恢复时查 [第六步说明](testing/第六步测试与交接说明.md)。

## 开发计划

| 文档 | 用途 |
| --- | --- |
| [A 开发计划](plans/后端A开发计划.md) | 手机主机、网络、数据库基础和图片工具的职责与原始验收标准 |
| [B 开发计划](plans/后端B开发计划.md) | 发布、查询、申请和业务状态处理的职责与原始验收标准 |
| [前端开发计划](plans/前端开发计划.md) | 正式界面、已有方法复用、页面交互和最终界面验收 |

A、B 计划中的早期时间安排用于解释分工，不代表现在仍要从第一步重新开发。前端按当前计划继续推进，A、B 配合对接和问题修复。

## 接口约定

[共同接口约定](api/共同接口约定.md) 只保留这一份。接口签名、字段和状态变化在这里更新；人员计划说明怎么使用它，不各自维护另一套接口。

实际 Java 调用还应结合前端计划和 A B 联调交接清单，尤其注意 LanApiClient 与 LostFoundApi 两种回调的包装层不同。

## 后续文档放哪里

- 调整人员任务，更新 `plans` 中对应的开发计划。
- 改接口或字段，更新 `api/共同接口约定.md`，同时通知调用方。
- 记录前端验收或新的联调结果，放入 `testing`，注明日期和已测范围。
- 增加或移动文件，同步更新本导航和相关链接；根 README 只保留入口，不复制整份计划。
