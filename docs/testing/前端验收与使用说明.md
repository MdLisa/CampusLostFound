# 前端运行与验收说明

更新日期：2026-11-08。分支：`前端`；合并目标：`master`。

## 完成内容

正式页面使用 Java、XML、普通 Activity 和现有 Material 组件，包含入口、主机、连接、信息首页、物品详情、发布、我的记录和收到的申请。

| 页面 | 主要功能 | 复用调用 |
| --- | --- | --- |
| 入口、主机 | 角色选择、主机启停、地址显示 | 原 HostActivity、ServerManager |
| 连接 | 地址检测、昵称进入、身份恢复 | connect、createSession、restoreSession |
| 首页 | 浏览、标题搜索、类型分类与状态筛选 | listPosts |
| 详情 | 文字与图片、认领或拾获线索、站外完成、关闭 | getPost、loadImage、submitClaim、resolvePost、closePost |
| 发布 | 表单校验、无图或单图发布、压缩预览与移除 | ImageCompressor、publishPost |
| 我的记录 | 我的发布、我的申请、状态筛选、取消申请 | getMyPosts、getMyClaims、cancelClaim |
| 收到的申请 | 查看证明及联系方式、拒绝、确认交接 | getReceivedClaims、rejectClaim、confirmClaim |

页面统一使用简体中文，支持浅色、深色和系统字号。公共网络、身份、图片与业务工具直接复用，接口字段、状态、协议、数据库和依赖保持原约定。

## 构建与运行

在 Android Studio 中打开项目根目录，按现有工程配置完成同步，选择设备后运行。所有设备安装同一个主程序 APK。

在项目根目录执行命令行检查：

```bash
# macOS / Linux
sh ./gradlew assembleDebug lintDebug testDebugUnitTest
```

```powershell
# Windows PowerShell
.\gradlew.bat assembleDebug lintDebug testDebugUnitTest
```

APK 默认位于 `app/build/outputs/apk/debug/app-debug.apk`。使用 macOS / Linux 时，也可运行 `bash scripts/build-debug.sh` 构建并复制主程序到本机安装目录。

## 三台设备联调

1. 三台设备安装同一主程序，连接可互访的同一无线网络或热点。
2. 甲进入主机页并开启主机，全程保持主机页前台；乙、丙填写甲显示的实际地址，各自以昵称进入。
3. 乙发布一条带图招领；丙刷新、搜索、查看详情并提交特征证明与联系方式。
4. 丙在“我的记录 → 我的申请”查看记录；乙在“我的记录 → 我的发布 → 详情 → 查看收到的申请”处理。
5. 模拟线下交接后，乙确认归还完成；双方刷新，核对帖子已完成、目标申请已完成交接。
6. 使用不同的新帖子测试取消、拒绝、寻物线索、站外完成和关闭；同一身份取消或被拒绝后不能再次申请同一帖子。
7. 甲停止主机后，乙、丙刷新应显示失败；甲重新开启后可以继续查询。使用相同地址普通重启时，原数据和身份应保留。

主机退出前台会停止服务，重新进入后需手动开启。更换客户端填写的基础地址会清除旧身份。卸载或清空主机数据会删除原记录。

## 核对重点

- 发布、申请、拒绝原因的字段校验正确；等待请求时防止重复点击。
- 我的发布与申请归属正确；本人不能申请自己的帖子，公开页面不显示申请证明和联系方式。
- 完成或关闭后，列表、详情、申请状态及按钮同步更新；关闭帖从公开列表隐藏。
- 加载、无记录与失败分别显示；断网后有恢复入口。
- 写入结果未确认时先查询对应记录，不自动重发；申请、拒绝与发布的输入内容尽量保留。
- 返回页面、选图返回和页面重建后可以继续操作；中文文字与深色、大字号下的控件正常显示。

详细字段和状态规则以 [前端开发计划](../plans/前端开发计划.md) 与 [共同接口约定](../api/共同接口约定.md) 为准。
